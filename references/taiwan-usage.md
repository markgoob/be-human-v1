# 臺灣用語規範（支語過濾）

所有輸出以臺灣繁體中文的慣用語彙為準。**「繁體字形」不等於「臺灣用語」**：把簡體字轉成繁體字形後，詞彙仍可能是中國大陸用語（俗稱支語）。

這一份與其他 reference 的性質不同。`structures.md`、`phrases-zh.md` 處理的是 AI 味，只在改寫任務裡啟用；本檔處理的是語域正確性，在**所有以繁體中文輸出的任務**中啟用，包括原創寫作、翻譯、以及一般對話回覆，不受 scene、力度檔位和 edit scope 影響。

判斷順序上，本檔優先於 `phrases-zh.md`：先確保詞是臺灣的，再談它像不像 AI。

## 2. 表外詞彙的判斷原則

對照表不可能窮盡，遇到表外的疑似支語時：

1. **判準以臺灣慣用為先**：教育部辭典、臺灣學術界與媒體的通行用法優先。不確定時，選臺灣讀者不會皺眉的那個。
2. **一詞多義要看義項**：「質量」「水平」「通過」「項目」這類詞不是全面禁用，而是特定義項禁用。翻譯物理文獻時 mass 當然譯「質量」。
3. **已歸化的借詞從寬**：「網紅」「打卡」「吐槽」等詞已進入臺灣日常語彙，可視語域使用；正式學術文件仍避免。
4. **語法層面的陸腔也要防**：「挺好的」→「蠻好的 / 很好」；「⋯⋯來著」刪除；萬用動詞「整」「搞」在正式文件中改為具體動詞。

## 3. 英文命名禁止無意義音譯

為檔案、變數、專案、skill、函式等取英文名稱時，禁止把中文詞彙以漢語拼音音譯充當英文（如 `de-ai-wei`、`bianzheng-tool`、`yinyue-analyzer`）。這是中國常見的命名習慣，對不諳中文的讀者是一串無意義音節。應使用語意對應的真實英語詞彙（`de-ai-tone`、`pattern-diagnosis`、`music-analyzer`）。

例外：專有名詞本來就以音譯通行者不在此限，如人名、地名（Taipei）、以及已有固定羅馬化的術語（qi、yin-yang、guqin 這類在英語文獻中已約定俗成的詞）。判準是：英語讀者查得到這個詞嗎？查不到就翻譯，查得到就沿用。

## 4. 與 protected spans 的關係

`protected-spans.md` 的禁改範圍優先於本表。落在下列範圍內的支語**照原樣保留**，不要順手改：

- 直接引文與引用原文
- 程式碼、命令、設定檔、API 欄位名、錯誤訊息
- 專有名詞、產品名、規格書中的固定術語
- 使用者明確要求保留原文風格的段落

改寫他人文字時，本表的替換屬於一般改寫動作，受 edit scope 約束：`in-place` scope 下仍可替換（換詞不改結構），但不得因此刪句或併句。
